    Подзадача 3: Вызов парсера через очередь (Celery + Redis)

    Что сделано:

    • Установлены зависимости: Celery, Redis, fastapi, aiohttp, asyncpg, beautifulsoup4.
    • Реализована фоновая Celery-задача parse_task, которая запускает парсер.
    @celery_app.task(name="tasks.parse_task")
def parse_task():
    parser_url = "http://parser_app:8000/parse"
    try:
        response = requests.post(parser_url)
        response.raise_for_status()
        return response.json()
    except requests.RequestException as e:
        return {"error": str(e)}
    • Добавлен эндпоинт /async-trigger-parse:
    • При вызове этот маршрут ставит задачу в очередь Redis.
    • Возвращает task_id сразу, не дожидаясь завершения парсинга.
    @router.post("/async-trigger-parse")
async def async_trigger_parse():
    task = parse_task.delay()
    return {"message": "Parsing started", "task_id": task.id}
    • Добавлен эндпоинт /task-status/{task_id}:
    • Позволяет узнать статус выполнения задачи (например, PENDING, STARTED, SUCCESS, FAILURE).
    @router.get("/task-status/{task_id}")
async def get_task_status(task_id: str):
    task_result = AsyncResult(task_id, app=celery_app)
    return {
        "task_id": task_id,
        "status": task_result.status,
        "result": task_result.result if task_result.ready() else None
    }
 ```

- В `docker-compose.yml` добавлены сервисы:
  - `redis` — брокер сообщений
  - `celery_worker` — исполняет фоновые задачи

    version: "3.8"

    services: main_app: build: context: ./main_app ports: - "8000:8000" depends_on: - db - redis env_file: - .env command: uvicorn main:app --host 0.0.0.0 --port 8000 working_dir: /app volumes: - ./main_app:/app

    parser_app: build: context: ./parser_app ports: - "8001:8000" depends_on: - db env_file: - .env working_dir: /app volumes: - ./parser_app:/app

    celery_worker: build: context: ./main_app depends_on: - redis - db env_file: - .env working_dir: /app volumes: - ./main_app:/app command: celery -A celery_main.celery_app worker --loglevel=info -Q parsing

    redis: image: redis:7-alpine ports: - "6379:6379"
